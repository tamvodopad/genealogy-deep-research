# Вятская губерния (Кировская обл., север Удмуртии, части Татарстана и Марий Эл)

Уезды губернии разошлись по разным современным регионам — **архив выбирается по уезду и периоду**: Глазовский, Сарапульский, частично Малмыжский и Елабужский уезды → ЦГА Удмуртии (см. `udmurtia.md`) и ГА РТ (`tatarstan.md`); советские дела после передачи территорий — в архиве той области/республики, куда отошёл район, и в каком году.

## ЦГАКО (Киров) — `cgako.ru`
- Сайт — Vue SPA. Списки файлов описей: JSON `/API/v0/pages/<код>` → `/static/page_files/<fname>`. Имена файлов в zip — в кодировке cp866 (распаковывать python `zipfile` с перекодировкой имён).
- Машинописные описи (PDF-картинки): `pdfimages` → увеличить ×3 → `tesseract -l rus --psm 6`. На macOS в multiprocessing обязателен `if __name__ == '__main__':`. Описи в `.doc` → `textutil -convert txt`. Текстовые PDF → `pdftotext -layout`.
- Рукописные описи OCR не берёт → vision-агенты (~80 страниц на агента), с правилами передачи текста (см. `../verification.md`).
- Сверка: перечень испорченных дел; список оцифрованного (`Otsifrovano.pdf` или аналог на сайте). В некоторых фондах у дела два номера — **заказывать по архивному** (обведённому), не по делопроизводственному.
- База исповедных (`base/isp.php`) — reCAPTCHA проходит пользователь.
- Ревизии хранятся не все (обычно IV–X); I–III ревизии Вятской провинции — РГАДА.
- Официальный запрос: подписанное заявление PDF на e-mail архива (адрес — на сайте), ответ 1–2 мес., затем счёт на предоплату. Только черновик для пользователя.
- Сильные фонды для XX в.: лишенцы, облисполком, благочиния/духовная консистория (XIX в.).

## «Родная Вятка» — `rodnaya-vyatka.ru` ★★★
- `places/<id>` — административная история деревни, СНМ 1905; блоги с расшифровками ревизий и метрик.
- «Метрики → Места хранения» (`/metriki/storages`) — где лежат метрики, включая районные музеи (замена закрытому Госкаталогу).
- Списки награждённых медалью «За доблестный труд» 1946–48 (`/dobl-trud…`): читается curl'ом, пагинация ненадёжна — дедуп по id.

## Прочее
- Герценка (ВОУНБ, `vpeb`): ВГВ и ВЕВ — нужна регистрация; проще через Яндекс Архив `mass_media`.
- Краеведы: falenki.ru и др. — пересказы источников (проверяй, где слова пересказчика, а где источника).
- Музеи: Кировский областной краеведческий (платный удалённый поиск), районные музеи — метрики и подворные книги встречаются там.
