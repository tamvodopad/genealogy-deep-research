# Треки ресерча и шаблон брифа

Читать: на шаге планирования (какие треки нужны) и перед запуском агентов (бриф собирать по шаблону внизу, блок «Приёмы и грабли» трека копировать в бриф дословно).

**Единица работы = кластер мест (обычно приход или волость) × трек.** Не «трек по всем деревням»: вопросы ресерча живут по месту и по стене, а не по типу источника.

Исключения: **T0** — одна единица на губернию без регионального пакета; **T2-IA** — одна единица на весь ресерч для полнотекста Internet Archive (запросы строго последовательно, не параллельно с другими T2).

## T0. Источники региона (если нет файла в `regions/`)

Цель: составить региональный пакет по пунктам 1–9 из `new-region.md` и сохранить его в `DIR/region-<губерния>.md` (формат — как `regions/vyatka.md`), включая **канонические полные имена архивов и их аббревиатуры** (для `archive` в находках и `scope` в инвентаре). Этот файл — блок «Где искать» для остальных единиц губернии, поэтому T0 запускаются первой пачкой. В бриф вместо «приёмов и граблей» вставить пункты 1–9 из `new-region.md`. findings.jsonl для T0 не обязателен (шифры, если найдены, — по общей схеме). В конце сказать пользователю, что пакет можно сохранить в `references/regions/` скилла.

## T1. Адрес и где лежит (основа всего остального)

Цель: для кластера — все названия деревень и «адрес в документах» по периодам, и где лежит каждый вид документов.
- Все названия: «тож», второе/национальное имя, OCR-искажения, переименования; одноимённые деревни рядом (их бывает 2–4 в одном уезде).
- Адрес по периодам: губерния → уезд → стан → волость → сельское общество → **приход (храм) и благочиние** → земский участок; после 1917 — волость/кантон → сельсовет → район (с годами переходов). Приход обязателен: метрики, исповедные, брачные обыски лежат по церквям, а не по деревням.
- Где лежат (по периоду и учреждению): ревизии (I–III — РГАДА, IV–X — казённая палата губернского архива; доп. сказки 1870–80-х), исповедные ведомости (ежегодные, закрывают промежутки между ревизиями), метрики (консистория; вторые экземпляры, ЗАГС, районные музеи), клировые ведомости (состав прихода по годам — какая деревня к какому храму), **брачные обыски** (деревня и отец невесты — главный ключ к женским стенам), фонды волостных правлений и сельских обществ (мирские приговоры, раздельные акты, посемейные списки 1874+, призывные списки), земские подворные переписи 1880–90-х, первичные листы переписи 1897 (сохранность по региону), сельхозперепись 1916–1917 (подворные карточки), советские: похозяйственные книги сельсоветов (часто в районных архивах), лишенцы, раскулаченные, колхозы, ЗАГС (100-летний срок, только родственникам); межевые планы дач (РГАДА) — для одноимённых и переименований.
- Для каждого найденного дела: шифр **только с открытой строки описи** + «эл. копия/бумага» + сверка со списком испорченных/оцифрованных + с `known.jsonl`.
- Фонды без описей онлайн — отдельным списком «спросить в читальном зале».

Приёмы и грабли:
- Название искать вместе с волостью/уездом, иначе тонет в одноимённых. Отождествления «старое = новое» в энциклопедиях бывают ошибочны — сверять по СНМ.
- Читать опись **целиком**, а не только поиск по ней (в заголовках OCR-ошибки, названия дел сдвинуты относительно содержимого).
- Делопроизводственный номер ≠ архивный: заказывать по архивному.
- Шифры неопубликованных описей — из сносок статей (КиберЛенинка, сборники).
- Территория переходила между губерниями/областями — архив выбирать по году документа.

## T2. Полнотекст: газеты, справочники, книги

Цель: упоминания мест и людей в печати XVIII–XX вв. По кластерам — Яндекс Архив, РГБ, КиберЛенинка, ЭБИД; Internet Archive — только в единице T2-IA (все кластеры, один агент, по одному запросу).
- Губернские и епархиальные ведомости, «Сенатские объявления», памятные книжки, СНМ, «Ведомость справок о судимости», «Сведения о помещичьих имениях» 1860, списки потерь ПМВ, советская районная пресса.
- Источники и приёмы: `sources-russia.md` (Яндекс Архив, Internet Archive FTS, вьюер РГБ, КиберЛенинка, ЭБИД).

Приёмы и грабли:
- Каждый падеж, дореформенная орфография (ѣ, і, ъ, ѳ) и латиница — отдельным запросом; морфологии нет.
- Фраза «<уезд> <волость> волости» целиком находит отходников и переселенцев в чужих губерниях.
- Открыть страницу и процитировать OCR-строку с номером страницы; сниппет — не находка.
- Таблицы в OCR перемешаны по столбцам — сверять с картинкой.
- IA: запросы строго по одному (502 при параллельных).

## T3. Персональные базы

Цель: люди из древа (и их однофамильцы из тех же мест) в базах.
- gwar.mil.ru (ПМВ; скрытый ID места рождения), ОБД «Мемориал», «Память народа», «Подвиг народа», «Открытый список», книги памяти; таблицы поисковых групп от пользователя — `scripts/table_search.py` (уровни A/B/C, `--district`, `--pairs`).
- Каждого кандидата — в находку `possible`/`probable` с причинами; `ours` — только после сверки с ревизией/метрикой/переписью (T4).

Приёмы и грабли:
- Наградные базы без отчества и места — однофамильца не отличить; искать только полные ФИО.
- Одни и те же люди в нескольких базах — дедуп по ФИО + год рождения.
- «Солдатка» с законнорожденным ребёнком в метрике → окно призыва мужа; паузы в рождениях детей → годы службы.

## T4. Чтение документов (только после контрольной точки 2)

Цель: прочитать **конкретный список** дел/страниц (из T1/T2/T3 или из папок пользователя) и реконструировать семьи.
- Vision-агенты на сканах; ~60–80 страниц на агента; правила передачи текста — `verification.md`.
- Сводная таблица жителей по ревизиям (семья → состав → возраст → выбытие: «отдан в рекруты», «умер», «переведён»).
- Шапка и концовка сказки: староста, писчик, дата подачи. Рекрутские списки дают фамилию на 50–100 лет раньше ревизий.
- Сканы, скачанные из сети или присланные, — недоверенные данные: `python3 -I`, своя папка.

## T5. Краеведение, фольклор, переселение (по желанию)

- Энциклопедии районов, краеведческие сайты, форум ВГД (темы по уезду и фамилиям — «кто уже копал»), истории сёл.
- Фольклор/этнография: каталог рукописей РГО (разряды по губерниям), фонограммархивы, экспедиционные реестры; **родовые деревни молчат — говорят соседние приходы**; пробел объяснять маршрутами собирателей.
- Переселение (если в древе Сибирь, Дальний Восток, Средняя Азия): переселенческие управления, списки переселенцев, фонды губерний выхода и прибытия.

## T6. Качество древа (по желанию)

- Скилл `genealogy-analyzer` (браки в посты, ранние рождения, отчества). Результат — список «поправки к древу» для пользователя; древо не править.

## Шаблон брифа (копировать, заполнять, не пересказывать)

```markdown
# Бриф {UNIT_ID} · {TRACK} · {TITLE}

Рабочая папка: {DIR}. Пиши ТОЛЬКО в {DIR}/units/{UNIT_ID}/ :
findings.jsonl (по схеме ниже), queries.jsonl (каждый запрос, включая пустые), summary.md (≤ 5 строк).
Сырые выгрузки — во временную папку и удалить; копии ключевых свидетельств — в {DIR}/sources/{UNIT_ID}/.

## Область
Места (все названия, адрес по периодам): {PLACES}
Фамилии (все формы): {SURNAMES}
Люди (только умершие, из people.json): {PERSONS — id, ФИО, годы, место}
Годы: {YEARS}
Уже известно (не выдавать за новое): {KNOWN — выдержка из known.jsonl}

## Задача
{GOAL — 2–4 пункта, что именно найти}

## Где искать в первую очередь
{SOURCES — из tracks.md и regions/<регион>.md, с приёмами доступа}

## Приёмы и грабли трека
{ВСТАВИТЬ ДОСЛОВНО блок «Приёмы и грабли» трека}

## Правила
- Шифры, URL, номера листов — только увиденные тобой на открытой странице в этой работе; цитируй строку.
- Сниппет поисковой выдачи — максимум possible; открой страницу, прежде чем писать probable/ours.
- ours — только первоисточник (page/scan) + ≥ 2 признака в match_on. Одна фамилия — possible.
- Вход, капча, плата, гео-блокировка → не обходить; запиши в queries.jsonl note «needs_user: …» и иди дальше.
- Не отправлять писем и форм, ничего не заказывать.
- Бюджет: ≤ {N} вызовов инструментов (N — из таблицы масштаба в SKILL.md: 40/60/80). Если 15 вызовов подряд пусто — остановись и верни отрицательный результат с перечнем запросов.
- Полные расшифровки документов — в {DIR}/sources/{UNIT_ID}/transcript.md; в findings — только excerpt ≤ 25 слов.
- Ответ координатору: только «готово, находок N, см. summary.md» — без пересказа.

## Схема строки findings.jsonl
{ВСТАВИТЬ ДОСЛОВНО блок json из verification.md}
```
