# Общероссийские источники

Пометки: **★★★ / ★★ / ★** — насколько источник давал результат в реальных ресерчах; **✗** — пробовали, почти пусто; **(станд.)** — стандартный источник, в ресерчах этого скилла не обкатан, приёмы не проверены.

Доступ меняется. Если источник не открылся — запиши в журнал «не открылся, дата, ошибка» и иди дальше; не выдумывай, что там «ничего нет».

## Полнотекст и оцифрованные книги

### Яндекс Архив ★★★ — `yandex.ru/archive`
- Читается curl'ом без входа. Поиск: `/archive/search?text=…&index=mass_media|archive|books`, страницы `&pageNum=N` (10 на страницу). Данные — JSON в `pageProps` → `items[]` (`parentId`, `namepath`, `snippet`).
- Страница выпуска: `/archive/catalog/<id>/<n>` → `currentNode.textBlocks[].text`, `totalPages`, `sourceUrl`. Картинка: `/archive/api/image?id=…&type=preview`. Список номеров года отдаёт только первые 48.
- `mass_media` — губернские и епархиальные ведомости, «Сенатские объявления», советская пресса. `archive` — метрики, исповедные, ревизии архивов-партнёров (набор регионов ограничен — проверь, есть ли твой; если нет, раздел всё равно находит **выходцев** из твоих мест в чужих губерниях). `books` — СНМ, памятные книжки, «Сведения о помещичьих имениях» 1860, «Ведомость справок о судимости», списки потерь ПМВ.
- Операторы: `&` `|` `+`. Таблицы в OCR перемешаны по столбцам — открывай страницу и картинку.
- При капче — подождать, не обходить.

### Internet Archive, полнотекстовый поиск ★★★
- `https://archive.org/services/search/beta/page_production/?service_backend=fts&user_query=<запрос>&hits_per_page=50`
- Морфологии нет: **каждый падеж, дореформенную орфографию (ѣ, і, ъ, ѳ) и латиницу — отдельными запросами** («Ивановка», «Ивановки», «Ивановкѣ»…).
- 502 при 100 hits или параллельных запросах → запросы строго по одному.
- Много губернских ведомостей, трудов губернских учёных архивных комиссий (ГУАК), этнографических изданий со своим OCR.

### Вьюер РГБ ★★★ — `viewer.rsl.ru/ru/rsl<id>?page=N`
- Поиск внутри тома. «Ведомость справок о судимости» (1872–1929, крестьяне по губерниям/уездам/волостям): ~22% томов без текстового слоя — их только листать; встроенный поиск пропускает записи — полный прогон делать по OCR из IA, если том там есть.

### КиберЛенинка ★★ — `cyberleninka.ru`
- `POST /api/search` (с морфологией). Главная ценность — **архивные шифры в сносках статей** (ключ к неопубликованным описям). Полный текст иногда за капчей — не обходить.

### ЭБИД ★ — `docs.historyrussia.org`
- Операторы `+голод +уезд`; «Указатели → География». Сводки ВЧК–ОГПУ, события 1917–1920-х по волостям.

### Прочее
- НЭБ/rusneb, Госкаталог музейного фонда, culture.ru, Президентская библиотека — **могут быть закрыты из-за границы России** (при проверке из Европы в 2026 г. — закрыты). Спроси пользователя, есть ли доступ с российского IP; не обходи защиту.
- ГПИБ, gensearch.ru — ✗ (узкое покрытие).
- Памятные книжки губерний, «Списки населённых мест» (СНМ 1859–1876 по губерниям, поздние губернские 1890–1920-х), «Волости и важнейшие селения» (1880-е), адрес-календари — ищи в Яндекс Архиве `books`, IA, РГБ, НЭБ.

## Каталоги архивов (поиск дел)

### notarc.org ★★ (бывш. alertino)
- Без регистрации, ~200 результатов на запрос. Единственный агрегатор с **описями муниципальных (районных) архивов** ряда регионов.

### «Великие описи» ★★ — `inv.velikie.org`
- Агрегатор описей; покрытие неравномерное — проверь, есть ли твой архив и фонды, прежде чем делать вывод «дела нет». Частная служба «Великие предки» (velikie.org) делает заказы в РГИА/НА РБ и др. — цены и сроки сверяй на сайте, заказ делает только пользователь.

### РГИА — `fgurgia.ru` ★★
- Только через браузер (выдача AJAX в дереве jstree). Поиск по подстроке, несколько слов = AND. В заголовках OCR-ошибки (уезд может быть написан с ошибкой — ищи по корню).
- Если инструмент выполнения JS в браузере режет вывод со спецсимволами (`? & =`): собрать результат в `localStorage`, вывести в `<pre>`, прочитать текст страницы. Не больше ~8 страниц выдачи за вызов.
- Что там для крестьянских родов: Сенат (крестьянские споры), Департамент уделов, выкуп (ф. 577), межевание, духовное ведомство (ф. 796, 799 — консистории, церкви).

### Федеральные архивы (станд.)
- **РГАДА** — переписные книги XVII в., ландратские книги 1710–1717, I–III ревизии (фонд ревизских сказок и ландратских книг — сверить номер по путеводителю РГАДА), межевые планы.
- **РГВИА** — военное ведомство до 1918: послужные списки офицеров и чиновников, дела полков, потери ПМВ. Нижние чины XIX в. — в делах полков и в фондах губернских рекрутских присутствий (региональные архивы). Номера фондов — только по путеводителю на сайте архива.
- **ЦАМО** — Красная армия; персональные данные через ОБД «Мемориал» / «Память народа».

### Федеральные и региональные порталы
- Центральный фондовый каталог Росархива, сайты региональных архивов, ЕАИС отдельных регионов — см. `regions/` и `new-region.md`.
- **Фонды без описей онлайн** — записывай отдельно: «спросить в читальном зале / у исполнителя».

## Персональные базы (люди)

### gwar.mil.ru («Память героев Великой войны 1914–1918») ★★★
- `POST https://gwar.mil.ru/gt_data/?builder=Documents|Heroes|DocumentView`, нужен `curl -k`.
- Нечёткий поиск (близкие по написанию слова), слова — AND. В «Документах» индексируются только названия; данные до ~1922.
- **Ключевой приём: скрытый ID места рождения** у карточек — найдя одну карточку с нужной деревней, бери её place-ID и выгружай всех с тем же ID: так находятся записи при любых искажениях написания.
- CDN сканов бывает на техработах — повтори позже.

### Базы Второй мировой (станд.)
- ОБД «Мемориал» (`obd-memorial.ru`), «Память народа» (`pamyat-naroda.ru`), «Подвиг народа» (`podvignaroda.ru`). Искать по фамилии + месту рождения/призыва (район, сельсовет), варианты написания.

### Репрессии
- «Открытый список» (`openlist.wiki`) ★★; региональные книги памяти; «Бессмертный барак» (станд.). При публикации — проверять требования к маркировке организаций (Минюст), если они применимы.

### Таблицы поисковых групп (Excel) ★★★
- Послужные и формулярные списки XIX в., общие базы рекрутов, рекруты отдельных наборов, бежавшие из плена (ПМВ), прошения о переводах. Пользователь присылает файлы — гонять `scripts/table_search.py`.
- Наградные базы ПМВ обычно без отчества и места — однофамильца не отличить; полные совпадения ФИО всё равно проверить уровнем C.
- Одни и те же люди повторяются в нескольких базах (разные выгрузки одной группы) — дедуп перед подсчётом.

### Генеалогические сообщества (станд.)
- Форум ВГД (`forum.vgd.ru`) — темы по уездам/волостям/фамилиям: что уже найдено, где хранятся метрики, кто ходит в архив. FamilySearch (`familysearch.org`, каталог микрофильмов метрических книг — часть регионов). Pomnirod, nashipredki — истории сёл и выписки других исследователей ★★.

## Карты и география (станд.)
- `etomesto.ru` — старые карты (ПГМ, Менде, РККА, Шуберт) с наложением; помогает с исчезнувшими деревнями и одноимёнными.
- Википедия/энциклопедии районов — для АТД, но **отождествления «старое название = новое» там бывают ошибочными** — сверяй с СНМ.

## Фольклор и этнография
- Научный архив РГО, каталог рукописей Д. К. Зеленина: **разряды по губерниям** (номер разряда ищи в оглавлении каталога; губерния могла поменяться — проверь все). Копии платно, по e-mail.
- `elib.rgo.ru` — печатные издания (поиск внутри книги `?searchPhrase=`).
- `bookplaces.ru` — география литературы; данные одним JSON (`openfolio.ru/bookplaces-data/literature.json`), фильтровать по квадрату координат.
- Фонограммархивы консерваторий и институтов — онлайн обычно только реестры; путь — письмо (черновик пользователю).
- Принцип: **родовые деревни часто «молчат» — ищи соседние приходы** и объясняй пробел маршрутами собирателей (программы РГО через духовенство, лингвистические экспедиции к нерусским народам, миссионерские и статистические обследования).
